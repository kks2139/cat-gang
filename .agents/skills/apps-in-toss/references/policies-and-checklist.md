# 앱인토스 정책, 심사 체크리스트 & 콘솔 가이드

앱인토스 미니앱의 출시 승인 정책, 카테고리별 규제 사항, 심사 전 점검 체크리스트 및 콘솔 MCP 활용 안내입니다.

---

## 1. 서비스 오픈 및 콘텐츠 정책

### 1-1. 출시 불가 카테고리
1. **가상자산 / NFT / 디지털 자산 거래**: 법적 요건과 무관하게 자산 손실 및 리스크 방지를 위해 입점 불가.
2. **현금 환전 / 자금세탁 위험 서비스**: 앱 내에서 현금 또는 유사 자산을 직접 교환/환불하는 구조 불가.
3. **사행성 및 베팅성 콘텐츠**: 복권, 불법 베팅, 사행성 유도 서비스 불가.
4. **금융/대출/송금 서비스**: 사전 승인되지 않은 대출, 보험, 카드, 증권 등 금융 상품 직접 중개 불가.
5. **투자 자문 / 리딩방 / 유료 종목 추천**: 개인 투자 의사결정에 영향을 주는 유료 정보 서비스 불가.
6. **의료 행위 직접 연결 / 병원 예약 수수료**: 비대면 진료, 병원 광고비 수취 모델 불가 (공공데이터 기반 단순 정보 조회는 조건부 가능).
7. **정치적 목적의 서비스**: 선거 운동, 정당 홍보, 정치 성향 테스트 등 불가.
8. **단순 자사 홍보용 랜딩 앱**: 실질적 앱 내 완결 기능 없이 회사 홍보만 수행하는 앱 불가.

### 1-2. 외부 앱 설치 유도 및 외부 링크 제한
- **자사 앱 설치 유도 절대 금지**: "앱을 다운로드하면 쿠폰 증정", "더 많은 기능은 전용 앱에서" 등의 유도 문구/배너/링크 금지.
- **외부 웹 결제 금지**: 외부 사이트로 이동하여 결제하거나 가입을 요구하는 플로우 금지 (미니앱 안에서 완결되어야 함).
- **허용되는 외부 링크**: 법적 필수 고지(개인정보처리방침 등), 공공기관 페이지, 단순 정보 참조 링크에 한함.

### 1-3. 생성형 AI 관련 법적 준수 사항 (필수)
1. **사전 고지 의무**: 서비스 진입 시 또는 AI 기능 사용 시 "생성형 AI를 활용한다"는 사실을 명확히 안내.
2. **AI 산출물 표시 의무**: AI가 생성한 결과물(텍스트, 이미지 등)에는 사용자가 즉시 알 수 있는 라벨/배지/워터마크 표시 필수.

## 2. 조건부 허용 카테고리별 필수 요건

### 2-1. 웹보드 게임 (포커, 맞고, 체스, 장기 등)
- 게임물관리위원회(GRAC) 등급분류 필증 필수 (해외 IARC 등급 인정 불가).
- 만 19세 이상 성인 본인확인 연동 필수.
- 게임 내 확률형 아이템 확률 정보 명시.
- 고객센터 문의 창구 및 결제 한도 관리 제공.

### 2-2. 만남 · 소개팅 · 소셜 매칭
- 법인 사업자 등록 필수.
- 만 19세 이상 성인 본인인증 필수.
- 허위 프로필 검증 프로세스 및 24시간 내 신고 대응 프로세스 운영.
- 원클릭 사용자 신고 및 차단 기능 제공.

### 2-3. AI 채팅 · 상담 서비스
- 위험 키워드 및 불법/유해 문맥 필터링 시스템 구축.
- 자살/자해/범죄 관련 발화 시 즉각적인 안전 응답 프로토콜 작동.
- 교육용/가상 설정을 빙자한 위험 질문 우회 시도 원천 차단.

### 2-4. 중고거래
- 이용자 간 직거래만 허용 (앱 내 결제 PG/토스페이 탑재 금지).
- 거래 금지 품목(의약품, 동물, 무기, 불법복제물 등) 필터링 및 명시.
- 앱인토스가 거래 당사자가 아님을 명시한 운영약관 고지.

## 3. 심사 전 최종 체크리스트

### 접속 & 기능 완결성
- [ ] 미니앱이 10초 이내에 정상적으로 실행되고 로딩이 완료되는가?
- [ ] 콘솔에 등록된 '앱 내 기능' 및 앱 스킴이 모두 정상 동작하는가?
- [ ] 토스 로그인 사용 시, 서비스 설명 인트로 화면 및 약관 화면이 정상 노출되는가?
- [ ] 사용자 식별키(`User.getAnonymousKey`)가 정상 발급되고 재접속 시 데이터가 유지되는가?

### 네비게이션 & UI/UX
- [ ] 안드로이드 하드웨어 백버튼 클릭 시 뒤로가기 또는 정상 종료되는가?
- [ ] 첫 화면에서 뒤로가기를 누르면 미니앱이 깔끔하게 종료되는가?
- [ ] 토스 상단 네비게이션 바와 자체 뒤로가기 버튼이 중복 표시되지 않는가?
- [ ] Safe Area(상단 노치, Dynamic Island, 하단 바) 여백이 확보되어 UI가 가려지지 않는가?
- [ ] 다크패턴(진입 즉시 바텀시트, 뒤로가기 방해 팝업, 닫기 없는 트랩)이 없는가?
- [ ] 다이얼로그의 취소/닫기 버튼 텍스트가 **'닫기'**로 되어 있는가?
- [ ] 하단 탭바를 사용할 경우 **플로팅 탭바** 형태로 구현되었는가?

### 보안 & 안정성
- [ ] `eval()` 등 외부 스크립트 실행 코드가 없는가?
- [ ] `window.location.replace` 등으로 외부 도메인 이동을 강제하지 않는가?
- [ ] SSR이 아닌 CSR/SSG 방식으로 빌드되었는가?
- [ ] 모든 API 통신은 HTTPS, 웹소켓은 WSS를 사용하는가?

### 결제, 광고 & 사운드
- [ ] 실물 결제는 `TossPay`, 디지털 재화는 `IAP`를 사용하는가?
- [ ] 인앱 결제 및 광고 재생 시 배경음악이 일시정지되고, 완료 후 재개되는가?
- [ ] 인앱 광고는 사전에 로드(`loadFullScreenAd`)되어 딜레이 없이 재생되는가?
- [ ] 공유 링크에 `intoss://` 정식 스킴을 사용하는가?

## 4. AI 콘솔 MCP 연동 요약

앱인토스 콘솔 MCP (`apps-in-toss-console`)를 연결하면 AI 채팅창에서 바로 워크스페이스 관리 및 번들 배포를 수행할 수 있습니다.

### MCP 등록 커맨드
```bash
# Claude Code
claude mcp add apps-in-toss-console --transport http https://mcp.toss.im/adapters/apps-in-toss-console/mcp --client-id mcp-gateway

# Codex
codex mcp add apps-in-toss-console --url https://mcp.toss.im/adapters/apps-in-toss-console/mcp --oauth-client-id mcp-gateway
```

### 주요 MCP 도구 목록
- `workspace_list`, `miniapp_list`, `miniapp_get_status` : 앱 상태 조회
- `bundle_upload`, `bundle_submit_review`, `review_get_feedback` : 번들 업로드 및 검수 관리
- `dashboard_dau`, `dashboard_revenue_iap`, `dashboard_revenue_iaa` : 지표 및 매출 통계
- `push_template_create`, `push_send_scheduled` : 푸시 메시지 발송 관리
